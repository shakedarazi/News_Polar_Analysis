## המשימה הבאה: `RepairModule.tsx`

המתכון שהוכח על שבעת האחרים:

1. לקרוא את המודול ואת `facts.repair`.
2. לצמצם ל־**2 לשוניות / 4 פאנלים**. פאנל שכל תוכנו מנגנון, מצב נתונים או
   היפותזה — נמחק.
3. להוריד כל `Caveat`; לקפל את הגבול לתוך משפט הפאנל היכן שבלעדיו המספר מטעה.
4. כל מונח נושא־טענה מוגדר **במשפט שבו הוא מופיע**. קודם השאלה, אחר כך המספר.
5. מקרא בשפה פשוטה מתחת לכל טבלה, גרף וציון — **עם שני קצות הטווח**.
6. כל פאנל = החלטה, החלופה בשמה, ומה זה קונה. גוף 18px, מספרי כותרת ~34–38px.
7. אימות: `npx tsc --noEmit`, ‏`npm run lint`, מדידת מילוי בדפדפן ב־1920×1080,
   `PYTHONPATH=. pytest tests/ -q` (222 עוברים).
8. לתקן כל סעיף בפנקס שהבטיח משהו שירד מהמסך, ולהוסיף סעיף **61** עם כל
   המחיקות וכל שדה `facts` שכבר לא נקרא.
9. קומיט לפי קומפוננטה.

מדידת המילוי, מהדפדפן על לשונית המודול:

```js
[...document.querySelectorAll('.dk-card')].filter(c=>c.clientHeight>100).map(c=>{const b=c.lastElementChild,i=b.firstElementChild;return Math.round(100*(i?i.scrollHeight:0)/b.clientHeight)+'%'+(c.scrollHeight>c.clientHeight?' CLIP':'')})
```

מתחת ל־60% פירושו תוכן שחסרה לו טענה, לא פריסה שצריך למתוח.

## יום התצוגה (מחר, מסך HDMI, מקומי)

```bash
./run_demo.sh
```

הוא כבר בודק ארטיפקטים, בונה מחדש את קובץ העובדות, בונה frontend ומרים את
שני התהליכים בלולאות watchdog. שלושה סיכונים אמיתיים:

1. **ענף שגוי** — ראו למעלה.
2. **`next dev` שרץ ברקע** מתנגש עם `npm run build` + `npm run start`
   שבסקריפט. להרוג אותו לפני.
3. **רזולוציה** — כל מדידות המילוי הן ב־1920×1080 ובזום 100%. לבדוק על המסך
   האמיתי, במסך מלא.

## ההחלטה על השילוב ב־main — אחרי התצוגה

נבדק ונסגר, לא לפתוח מחדש בלי סיבה:

- **למזג את הענף ל־main.** ‏51 קומיטים קדימה, תוספות בלבד, **אפס קונפליקטים**.
  הסיבה: הקוד לא ירקב על ענף צדדי.
- **בלי קישור בתפריט.** הקיוסק לוכד גולש רגיל — ‏`Esc`/`Backspace` מחזירים
  למפת המודולים ולא לאתר, והספרות 1–9 חטופות גלובלית. ‏`/demo` נשאר ראוט
  לא־מפורסם ששולחים כלינק.
- **עובדות סטטיות** כדי שהלינק יעבוד בפרודקשן: היום `useFacts()` פונה
  ל־`http://localhost:8010/facts` ישירות מהדפדפן, בניגוד לכל שאר האתר שעובר
  דרך route handlers כדי להימנע מ־CORS. הפתרון: להגיש את
  `explainer_facts.json` (‏82KB) כנכס סטטי של Next עם נפילה חזרה לשרת הדמו
  כשהוא קיים, ולהוסיף שורה לבנאי שכותב גם לשם. ‏`demo/data/` כולו gitignored,
  ואף בנייה ב־Vercel לא מייצרת אותו.
- ההצגה המונחית כבר נופלת לזרם מוקלט אחרי 5 שניות בלי backend, ו־`?mock=1`
  מכריח את זה.

**סייג:** קובץ העובדות מכיל כותרות ותגובות אמיתיות. הגשתו כנכס סטטי הופכת
אותו לציבורי — אותו סוג נתונים שהאתר כבר מגיש, אבל זו החלטה ולא פרט טכני.
