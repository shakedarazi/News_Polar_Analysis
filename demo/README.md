# שכבת הדמו — נחיל סוכנים חי (Multi-Agent Demo Layer)

שכבה נפרדת לגמרי מהפייפליין הדטרמיניסטי: קוראת מ־snapshot מקומי של נתוני
המערכת, לא כותבת שום דבר בחזרה, ולא נוגעת בקוד של `src/` או `pipeline/`.
נבנתה למיצג במכללה: מסך HDMI, לולאה של כ־5 דקות, קהל עובר.

## הפעלה

```bash
# פעם אחת, עם רשת, יום לפני המיצג:
source .venv/bin/activate
pip install -r demo/requirements.txt
PYTHONPATH=. python demo/snapshot/export_snapshot.py   # Neon → SQLite מקומי
PYTHONPATH=. python demo/snapshot/prepare_demo.py      # embeddings + אינדקס + כיול

# ביום המיצג (עובד גם בלי רשת):
./run_demo.sh                  # מצב מציג (HITL) — מתקדם בלחיצה
DEMO_AUTOPLAY=1 ./run_demo.sh  # לולאת קיוסק אוטונומית (בלי מציג)
```

`run_demo.sh` בונה את ה־frontend, מרים את שרת הסוכנים (‏:8010) ואת הדשבורד
(‏:3000/demo) עם watchdog שמרים כל תהליך שנפל תוך 2 שניות, ופותח Chrome במצב
kiosk. חזרות: `DEMO_SPEED=0.3 SKIP_BUILD=1 ./run_demo.sh`.

מצבים (`DEMO_MODE`): `auto` (ברירת מחדל — מנסה LLM חי דרך OpenRouter, ובכשל
ראשון עובר לבד למקומי), `offline` (דטרמיניסטי לחלוטין, מומלץ למיצג עצמו),
`live`. תג בפינת המסך מראה תמיד את המצב בפועל ("מודל ענן חי" / "מקומי ·
דטרמיניסטי").

## שליטה ידנית (HITL) ומבנה הסצנות

הדמו הוא רצף של **8 סצנות ממוקדות**, ובסוף כל סצנה הוא עוצר ב"שער" עד
שהמציג מקיש **רווח/Enter/חץ** או לוחץ על כפתור ההמשך שעל המסך:

1. **הארכיטקטורה** — הפייפליין הדטרמיניסטי, בסדר הכרונולוגי המדויק של
   הריצה המתוזמנת ב־GitHub Actions (crawl → windows → comments → lexicon →
   analyze → Postgres), ואז שכבת הסוכנים שמעל.
2. **איסוף — עוד בלי AI** — סקאוט ועץ ההחלטות לקישורים שבורים, בקצב אנושי.
3. **האלגוריתם — עדיין בלי AI** — לקסיקון בן שמחון על כתבה אמיתית + פאנל
   "כך זה נראה באתר Trust" עם ביאור לכל שדה (חלונות, דומיננטיות,
   audience_mean/p85).
4. **כאן נכנס ה־AI: אחזור (RAG)** — הרעיון (תקדימים מתויגים, לא החלפת
   הכתבה), שכנים אמיתיים, והשוואת הטוקנים.
5. **שלושת הסבבים** — סיווג + ביקורת + דיבייט, עם שער אחרי כל סבב.
6. **למידה** — הקשת 57→75→88 + מה נכנס לזיכרון בפועל.
7. **כלכלת טוקנים** — עלות הריצה מול אומדן "הכל ב־LLM", והבנצ'מרק ב־CI.
8. **סיכום** — נשאר על המסך עד שמתקדמים; ההמשך מתחיל ריצה חדשה.

ב־`DEMO_AUTOPLAY=1` כל שער ממשיך לבד אחרי ~12 שניות (לולאת קיוסק/CI);
במצב מציג השערים מחכים בלי הגבלת זמן, וה־backend **מתעלם** מבקשות
restart אוטומטיות כדי שדף ישן/תקוע לא יפיל מצגת חיה.

## מה רץ שם

חמישה סוכנים על אוטובוס הודעות אסינכרוני (`demo/core/`), עם היררכיית Tiers:

| סוכן | Tier | תפקיד |
|---|---|---|
| 🛰️ סקאוט | 2 | איסוף; עץ החלטות לקישורים שבורים (selector → archive.org → RSS → דילוג) |
| 📖 לקסי | 1 | הליבה הדטרמיניסטית — ניתוח לקסיקון הקיטוב (מחקר אלמוג בן שמחון) |
| 🗂️ הספרנית | 3 | אחזור RAG מאינדקס וקטורי (multilingual-e5-small) |
| 🤖 נובה | 4 | סיווג: baseline → ‏RAG+kNN/LLM → ‏+זיכרון מצטבר |
| 🎓 עמית | 5 | מבקר: מערער, פותח דיבייט, מכריע, מזין למידה |

שלושה סבבים על סט קבוע של 24 כתבות אמיתיות: **בלי RAG → עם RAG → עם
RAG+למידה**, עם עקומת דיוק שעולה על המסך (אבלציה חיה). בסוף — סיכום ואיפוס
אוטומטי.

## פנקס היושרה (מה אמיתי ומה מפושט) — לקרוא לפני שמציגים

דברים שחשוב להגיד נכון אם שואלים:

1. **הסקרייפינג בזמן המיצג מדומה.** הכתבות נטענות מה־snapshot המקומי;
   תרחישי "הקישור שבור" מתוסרטים מראש כדי שעץ ההחלטות יודגם בצורה חוזרת
   ואמינה. עץ ההחלטות עצמו (הלוגיקה, הסדר, הדיווח) רץ באמת. הקרולרים
   האמיתיים של המערכת הם אלה שאספו את הנתונים מלכתחילה (`src/crawling/`).
2. **סדר הכתבות בסבבים "לוהק" מראש** (`prepare_demo.py` מחפש שיבוץ שבו
   הקשת 57%→75%→88% נראית בבירור). מנגנוני השיפור עצמם אמיתיים — retrieval
   באמת משפר סיווג, והאינדקס באמת גדל בין סבבים — רק הדגימה נבחרה כך
   שהאפקט האמיתי יהיה ברור ב־5 דקות. המספרים הם ביצועים אמיתיים של השיטות.
3. **ה"למידה" היא לא אימון מודל** — זה זיכרון מצטבר: דוגמאות מתוקנות
   מהדיבייטים נוספות לאינדקס ול־few-shots. שיפור אמיתי, בלי backprop.
4. **במצב offline הדיבייטים מתוסרטים מתבנית** — אבל כל מספר בהם אמיתי
   (הצבעות שכנים, מוני לקסיקון). במצב live אלה תורות LLM אמיתיות.
5. **מדדי הדיוק נמדדים מול תיוג הייחוס הקיים במאגר** (סיווג ה־LLM ההיסטורי
   של הפייפליין), לא מול תיוג אנושי.
6. **חיווי העלות** מחושב ממחירון OpenRouter על טוקנים אמיתיים; במצב offline
   העלות היא באמת 0.
7. **השוואות הטוקנים הן אומדנים** ומסומנות כך על המסך: בסצנת ה־RAG
   (כתבה מלאה מול כותרת+שכנים) ובסצנת הכלכלה ("אילו הכל היה LLM") ההמרה
   היא ~3 תווי עברית לטוקן. סכום העלות של הריצה עצמה — אמיתי.
8. **פאנל "כך זה נראה באתר" הוא שחזור נאמן של כרטיסי המוצר**, לא iframe של
   האתר החי — כדי שהקיוסק לא יהיה תלוי ברשת. כל הערכים בו אמיתיים
   מה־snapshot.

## ארכיטקטורה

```
demo/
  snapshot/   export_snapshot.py (Neon→SQLite), prepare_demo.py (אינדקס+כיול)
  core/       events.py (SSE broker), agent.py, classify.py (לוגיקה משותפת),
              index.py (אינדקס וקטורי), llm.py (OpenRouter+degrade), memory.py
  roles/      agents.py — חמשת הסוכנים
  runner.py   מכונת הסצנות (8 סצנות, 3 סבבים, שערי HITL, סיכום, איפוס)
  core/control.py  בקר השערים (advance/autoplay)
  server.py   FastAPI: ‏/events (SSE), ‏/state, ‏/control/advance, ‏/control/restart
  EVENTS.md   חוזה האירועים מול הדשבורד
frontend/src/app/demo/  דף הקיוסק (Next.js)
.github/workflows/agent_benchmark.yml  בנצ'מרק חינמי ב־CI
```

הערה לגבי ה־RAG: האינדקס הוא מטריצת numpy מנורמלת עם דמיון קוסינוס — לא שרת
vector-DB. בגודל הזה (~1.2K קטעים) זה מהיר יותר, דטרמיניסטי, ואין לו מה
ליפול מול קהל. ה־embeddings אמיתיים (multilingual-e5-small, מחושבים מראש).

## צ'ק־ליסט חזרה גנרלית (יום לפני)

1. `pip install -r demo/requirements.txt` בסביבה הוירטואלית.
2. עם רשת: `PYTHONPATH=. python demo/snapshot/export_snapshot.py` ואז
   `PYTHONPATH=. python demo/snapshot/prepare_demo.py` — ולוודא שההדפסה
   מסתיימת ב־arc עולה (בסביבות ‎0.57 → 0.75 → 0.88).
3. `DEMO_MODE=offline DEMO_SPEED=0.02 PYTHONPATH=. python demo/benchmark.py`
   — חייב לצאת בהצלחה (זו בדיוק ריצת ה־CI).
4. חזרה מלאה בקצב מהיר: `DEMO_SPEED=0.3 SKIP_BUILD=1 ./run_demo.sh`,
   לעבור את כל 8 הסצנות עם המקלדת.
5. **לסגור כל טאב ישן של ‎/demo** מהפעלות קודמות (גם בחלונות כרום אחרים!)
   — דף ישן שמחובר ל־backend עלול לשלוח פקודות מתקופת קוד קודמת. ה־backend
   מתעלם מ־restart במצב מציג, אבל עדיף נקי.
6. ביום עצמו: `./run_demo.sh` (מצב מציג). **קליק אחד על המסך** אחרי שהדף
   עולה — כדי שהמקלדת תיקלט בחלון הקיוסק.

## מה עושים אם X נופל (ביום המיצג)

- **הדף מציג "מצב הדגמה"** — ה־backend לא נגיש. ה־watchdog של
  `run_demo.sh` אמור להרים אותו תוך שניות; הדף חוזר ל־live לבד (בדיקה כל
  ‎15 שניות). אם לא — ‎Ctrl+C ל־`run_demo.sh` ולהריץ שוב עם `SKIP_BUILD=1`.
- **המקלדת לא מתקדמת** — קליק אחד על המסך (פוקוס), או ללחוץ ישירות על
  כפתור ההמשך. תמיד אפשר: `curl -X POST localhost:8010/control/advance`.
- **הדמו נראה תקוע באמצע סצנה** (לא בשער) — `curl -X POST
  localhost:8010/control/restart` יעבוד רק בקיוסק; במצב מציג פשוט להרוג את
  תהליך `demo/server.py` — ה־watchdog מרים אותו נקי תוך 2 שניות והדף מתחבר
  מחדש לריצה חדשה.
- **מצב live מגמגם** — לא לגעת: אחרי כשל אחד המערכת עוברת לבד ל"מקומי ·
  דטרמיניסטי" (רואים בתג). אפשר גם להתחיל מראש עם `DEMO_MODE=offline`.
- **אין קול/אין עכבר/אין כלום** — הנתונים והקוד מקומיים לגמרי; ריצת
  `?mock=1` בדפדפן (`localhost:3000/demo?mock=1`) מציגה תסריט מלא גם בלי
  backend בכלל.
